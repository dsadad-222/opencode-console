代理档 0

模型名不带 -free 就走协议代理，支持 tools / tool_use（含流式）。上游 —，吃的是号池额度，不是免费额度。

ⓘ

代理档不受本页的黑名单/别名影响（那套只管免费池）。要停用某个代理模型，直接在上游侧拉黑。

外部 provider 0

厂商官方免费层（NVIDIA NIM / OpenRouter 等），标准 OpenAI 兼容端点， 原生支持 tools，既不经过号池、也不经过 serve。 模型名带前缀：nvidia/…、openrouter/…:free。

!

有 provider 还没配 Key。编辑 ext_providers.json 填 key， 或设置对应的环境变量；改完不用重启转发层。

ⓘ

免费档模型的上架/下架由上游决定，随时会变。控制台每小时静默巡检一轮，失败项会记录在概览页。

ⓘ

免费档现已支持工具调用（v17，两条协议都可以）： 靠提示词约定 + 输出解析实现，实测 6/7 模型稳定。模型不按格式输出时会退化成普通聊天 —— 不报错，但工具不会执行。要 100% 可靠请用代理档模型名，或用上面的外部 provider。

01 / NETWORK

出网方式

决定 opencode serve 出网是否走代理。改完需要重启 serve 才生效（转发层会在下次拉起时读取）。

ⓘ

历史事故：无条件设 HTTPS_PROXY 而 Clash 没开时，serve 状态仍显示 healthy，但所有模型返回空回复。所以默认「自动」。

02 / DEFAULTS

默认模型

客户端传空模型名时用哪个。留空 = 用列表第一个。

03 / MAINTENANCE

日志与巡检

日志清理每 6 小时跑一次；被删的是 SQLite 里的历史行，不影响转发层。

04 / BLACKLIST

黑名单

仍在 serve 列表里、但确定调不通的模型。加进来后不会再出现在 /v1/models。

05 / PIPE LIMITS

体量与超时

免费档（pipe 档）的关键参数。客户端报 Connection error 时先看这里。

ⓘ

这些值在转发层启动时从环境变量读取，控制台改不了，改完要重启 8893。

01 / ENDPOINT

OpenAI 兼容端点

http://127.0.0.1:8893/v1

支持 /v1/chat/completions 与 /v1/models。流式与非流式都支持。

curl http://127.0.0.1:8893/v1/chat/completions -H "Content-Type: application/json" -d '{"model":"deepseek-v4.1-flash-free","messages":[{"role":"user","content":"hi"}]}'
02 / DSH

接入 DSH

在 profiles/desktop/cordis.yml 里新增一个 provider：

opencode2: type: openai baseURL: http://127.0.0.1:8893/v1 apiKey: any models: - deepseek-v4.1-flash-free - nemotron-3-ultra-free

模型列表以本控制台「模型管理」为准，别照抄旧配置 —— 上游随时会下架。

03 / ANTHROPIC

Claude 系客户端

http://127.0.0.1:8893

支持 POST /v1/messages 和 /v1/messages/count_tokens。 流式严格按 message_start → content_block_* → message_delta → message_stop 发。

限制：不支持工具调用。转发层只搬运文本，tools / tool_use / tool_result 都不会被转换 —— 纯对话可用，但 Claude Code 那种靠工具干活的场景接过来会退化成聊天。
